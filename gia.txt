## 📚 CLASE 10: INTRODUCCIÓN A ANGULAR 17

### Comandos Básicos
```bash
npm install -g @angular/cli@17
ng new proyecto
ng serve  # o npm start
```

### 1. Interpolación
```typescript
// Component
nombre: string = "Mi aplicación";

// Template
<h1>{{nombre}}</h1>
```

### 2. Template Statements (Eventos)
```typescript
// Eventos básicos
<button (click)="saludar()">Saludar</button>
<input (keyup)="updateField($event)" />
<input (keyup.enter)="updateField()" />

// En component.ts
saludar() { /* lógica */ }
updateField(event?: any) { /* lógica */ }
```

### 3. Control Flow (Angular 17)
```typescript
// Condicionales
@if(active) {
  <a>El usuario está activo</a>
} @else {
  <a>Usuario desactivado</a>
}

// Bucles
nombres: Array<string> = ["Juan", "María", "Pedro"];

@for(name of nombres; track name) {
  <a>{{name}}</a><br>
}
```

### 4. Formularios NgModel
```typescript
// Importar en component
import { FormsModule } from '@angular/forms';

// En @Component
imports: [FormsModule]

// En template
<input type="text" 
       [(ngModel)]="user.name"
       [ngModelOptions]="{standalone: true}" />
```

## 📚 CLASE 11: COMPONENTES

### Crear Componente
```bash
ng generate component nombre-del-componente
```

### 1. @Input() - Recibir datos del padre
```typescript
import { Component, Input } from '@angular/core';

@Component({
  selector: 'app-hijo',
  template: `<p>Usuario: {{user.name}}</p>`
})
export class HijoComponent {
  @Input() user: { name: string; email: string };
}

// Uso en padre:
<app-hijo [user]="currentUser"></app-hijo>
```

### 2. @Output() - Enviar datos al padre
```typescript
import { Component, Output, EventEmitter } from '@angular/core';

@Component({
  selector: 'app-hijo',
  template: `<button (click)="enviarDatos()">Enviar</button>`
})
export class HijoComponent {
  @Output() dataEnviada = new EventEmitter<string>();

  enviarDatos() {
    this.dataEnviada.emit("datos del hijo");
  }
}

// Uso en padre:
<app-hijo (dataEnviada)="recibirDatos($event)"></app-hijo>

// En padre:
recibirDatos(data: string) {
  console.log(data);
}
```

### 3. Servicios
```bash
ng generate service nombre-del-servicio
```

```typescript
import { Injectable } from '@angular/core';

@Injectable({
  providedIn: 'root'
})
export class MiService {
  private datos: any[] = [];

  obtenerDatos() { return this.datos; }
  agregarDato(dato: any) { this.datos.push(dato); }
}

// Inyectar en componente:
constructor(private miService: MiService) {}
```

## 🔧 ESTRUCTURA COMPONENT ANGULAR 17

### Template Básico
```typescript
import { Component } from '@angular/core';
import { FormsModule } from '@angular/forms';

@Component({
  selector: 'app-ejemplo',
  standalone: true,
  imports: [FormsModule, OtroComponent],
  template: `
    <!-- Interpolación -->
    <h1>{{titulo}}</h1>
    
    <!-- Control Flow -->
    @if(mostrar) {
      <p>Contenido visible</p>
    }
    
    @for(item of items; track item) {
      <div>{{item}}</div>
    }
    
    <!-- Eventos -->
    <button (click)="handleClick()">Click</button>
    
    <!-- Formulario -->
    <input [(ngModel)]="texto" 
           [ngModelOptions]="{standalone: true}">
    
    <!-- Componente hijo -->
    <app-hijo [data]="miData" 
              (evento)="manejarEvento($event)">
    </app-hijo>
  `,
  styles: [`
    .clase { color: blue; }
  `]
})
export class EjemploComponent {
  titulo = "Mi App";
  mostrar = true;
  items = ["a", "b", "c"];
  texto = "";
  miData = { nombre: "test" };

  handleClick() { /* lógica */ }
  manejarEvento(data: any) { /* lógica */ }
}
```

## 💡 PATRONES PRINCIPALES

### Comunicación Padre → Hijo
```typescript
// Padre
<app-hijo [propiedad]="valor"></app-hijo>

// Hijo
@Input() propiedad: any;
```

### Comunicación Hijo → Padre
```typescript
// Hijo
@Output() evento = new EventEmitter<any>();
this.evento.emit(datos);

// Padre
<app-hijo (evento)="metodo($event)"></app-hijo>
metodo(datos: any) { /* usar datos */ }
```

### Estado Local
```typescript
export class Component {
  // Primitivos
  texto: string = "";
  numero: number = 0;
  activo: boolean = false;
  
  // Arrays
  lista: string[] = [];
  objetos: {id: number, name: string}[] = [];
  
  // Métodos
  agregar(item: string) {
    this.lista.push(item);
  }
}
```

## 🎯 CHECKLIST IMPLEMENTACIÓN

### ✅ Setup Básico
- [ ] `ng new proyecto`
- [ ] `ng generate component`
- [ ] Importar `FormsModule` si necesitas formularios
- [ ] Configurar `standalone: true`

### ✅ Template
- [ ] Usar `{{}}` para interpolación
- [ ] `@if/@else` para condicionales
- [ ] `@for(item of array; track item)` para listas
- [ ] `(evento)="metodo()"` para events
- [ ] `[(ngModel)]` para formularios

### ✅ Componentes
- [ ] `@Input()` para recibir datos
- [ ] `@Output() + EventEmitter` para enviar datos
- [ ] Importar componentes hijos en `imports: []`

### ✅ Debugging
- [ ] `console.log()` en métodos
- [ ] Verificar imports en cada component
- [ ] Usar `track` en `@for` loops
- [ ] `[ngModelOptions]="{standalone: true}"` para forms

---

## 🚨 ERRORES COMUNES

1. **FormsModule no importado** → `import { FormsModule }`
2. **Component no importado** → Agregar a `imports: []`
3. **@Input/@Output sin import** → `import { Input, Output, EventEmitter }`
4. **Track missing en @for** → Siempre usar `track item`
5. **ngModel sin standalone** → `[ngModelOptions]="{standalone: true}"`
